# Сборщик документов — для Codex, Kimi Code и других инструментов

**Полная карта системы — в файле `CLAUDE.md` в этой же папке. Прочитай его целиком, это
основной документ: пайплайн, профили, правила, скрипты, границы.** Здесь — только то, чем
работа отличается, если у тебя нет субагентов и слэш-команд.

## Чем заменить то, чего у тебя нет

| В `CLAUDE.md` написано | Что делать тебе |
|---|---|
| «зови субагента `source-extractor`» | сделай этот шаг сам по описанию из `.claude/agents/source-extractor.md` |
| «зови субагента `pdf-builder`» | сделай сам по `.claude/agents/pdf-builder.md` + скилл `.claude/skills/document-design/SKILL.md` |
| «двойной аудит свежим субагентом» | проверь сам **отдельным проходом по готовому PDF**, а не по своей же памяти о вёрстке: открой скриншоты страниц и перечитай текст заново |
| команда `/setup` | инструкция лежит в `.claude/commands/setup.md` — веди разговор по ней |
| команда `/pdf` | инструкция лежит в `.claude/commands/pdf.md` |

Скиллы и правила — обычные текстовые файлы: открывай и применяй, даже если твой инструмент
не умеет «скиллы» как отдельную сущность.

## Всё остальное — без изменений

Профиль обязателен, слаг на каждую работу, ни одного жёсткого цвета в вёрстке, данные автора
только из `context/автор.md`, честные границы вслух. Скрипты запускаются одинаково:
`.venv/bin/python scripts/<имя>.py`.

Один и тот же документ на любом инструменте должен собираться одинаково. Что-то не заводится —
скажи об этом прямо, не делай вид, что так и надо.
