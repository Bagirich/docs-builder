# Сборщик документов

> Система собирает готовый PDF-документ из того, что у человека уже есть: текст, статья,
> ссылка, запись разговора, скринкаст. Оформление берётся из **профиля** — «чей это документ».
> Работай автономно: решай сам, не спрашивай по мелочам.

## 1 · Как устроено

Любой источник превращается в один файл `ingest/normalized-<slug>.md`, он верстается в
HTML+CSS и печатается в PDF через headless-Chromium. Браузер обязателен: он даёт градиенты,
свои шрифты, эмодзи и настоящие кликабельные ссылки внутри PDF.

Ты — тонкий оркестратор. Тяжёлую работу отдаёшь трём субагентам:

| Субагент | Когда зовётся | Что делает |
|---|---|---|
| `source-extractor` | источник = ссылка, чужой PDF, запись, скринкаст | выкачивает, парсит, расшифровывает, чистит → `ingest/normalized-<slug>.md` |
| `pdf-builder` | всегда, на этапе вёрстки | собирает `guide-<slug>.html` из блоков, рендерит, прогоняет само-QA |
| `auditor` | всегда, после рендера | принимает готовый PDF **свежим взглядом**: смотрит страницы глазами, сверяет факты с источником |

⛔ **`auditor` — это НЕ тот, кто верстал.** Автор вёрстки свою ошибку не видит: он знает,
«как задумано», и глаз достраивает недостающее. Поэтому приёмку всегда делает отдельный агент.

Роли лежат в трёх форматах — для Claude Code, Codex и Kimi Code — и собираются из одного
источника: `.venv/bin/python scripts/sync_agents.py` (проверить, не разъехались ли:
`--проверить`). Правим только `.claude/agents/*.md`, остальное пересобирается.

## 2 · Профиль — первое, что нужно проверить

**Ни одного профиля → работу не начинаем**, сначала `/setup`: система должна знать, чей это
документ, иначе на обложке будет пусто. Профилей несколько, активный не назван — спроси одной
фразой. Профиль один — молча работай в нём.

- профили лежат в `профили/<имя>/profile.json`, активный записан в `профили/_активный`;
- `.venv/bin/python scripts/brand_build.py [имя]` — «запекает» профиль: собирает
  `context/theme.css` (цвета и шрифты) и `context/автор.md` (данные для страницы об авторе);
- ⛔ **в вёрстке ни одного жёсткого цвета и шрифта** — только переменные темы. Иначе документ
  нельзя пересобрать в другом профиле, а это главная возможность системы;
- ⛔ **данные об авторе — только из `context/автор.md`, дословно.** Нет факта — блок короче.

## 3 · Пайплайн

0. **Слаг.** В начале каждой работы придумай короткое имя (`<slug>`) и веди под ним все файлы:
   `ingest/normalized-<slug>.md`, `guide-<slug>.html`, `output/<Понятное-Имя>.pdf`, `qa-<slug>/`.
   Скрипты ingest и скринкаста принимают этот слаг флагом `--слаг <slug>` — передавай его всегда.
   Рядом может идти другая работа — в общие пути не пиши и чужие не трогай.
1. **Источник.** Текст/статья/готовая расшифровка — нормализуй сам. Ссылка, чужой PDF, запись,
   скринкаст — зови `source-extractor`.
2. **План страниц.** Разложи содержимое по страницам, назначь баланс тёмных/светлых 30/70,
   зафиксируй план в логе. Не спрашивай — решай.
3. **Вёрстка.** Одна `<section class="page">` = один лист A4, `overflow:hidden`: не влезшее
   молча обрезается, а не переносится. Планируй объём на страницу заранее. Зови `pdf-builder`. Он открывает скилл `document-design`, собирает HTML,
   рендерит, сам проверяет себя.
4. **Двойной аудит после рендера — не пропускать:**
   - **визуально** — скриншоты каждой страницы (`qa_screenshots.py`) просмотреть глазами:
     ничего не вылезает, картинки и графики отрисованы, заполнение ≥⅔;
   - **текстом** — тем же `auditor` (не тем, кто верстал): каждая цифра либо из источника,
     либо проверена; выдуманное — удалить. Орфография и единый тон.
   - Нашли дефекты — починить и пере-рендерить, аудит повторить.
5. **Итог:** путь к PDF + метрики (страниц, баланс, ссылок, картинок) и честный список того,
   что не получилось.

## 4 · Что где лежит

- **Правила:** `.claude/rules/qa-checklist.md` (проверка перед сдачей) ·
  `.claude/rules/learning-guide-spec.md` (инструкции со скриншотами — обязательно для мануалов).
- **Оформление:** скилл `.claude/skills/document-design/SKILL.md` — роли цветов, кегли, блоки, визуал.
- **Шаблоны:** `templates/skeleton.html` (каркас + весь CSS) · `templates/blocks/` (8 блоков) ·
  `templates/icons.svg`.
- **Команды:** `/setup` — завести или поправить профиль · `/pdf` — собрать документ.
- **Учебный материал для первой пробы:** `учебные-материалы/`.

## 5 · Скрипты

Разовая установка — `bash scripts/setup.sh` (создаёт `.venv`, ставит зависимости, шрифты,
Chromium; запускать повторно безопасно). Дальше всё через `.venv/bin/python`.

| Скрипт | Зачем |
|---|---|
| `brand_build.py` | запечь профиль → тема и данные автора |
| `sync_agents.py` | собрать роли для Codex и Kimi из `.claude/agents/` (и сверить, не разъехались) |
| `selftest.py` | самопроверка: собирает пробную страницу в цветах профиля |
| `ingest/fetch_url.py` · `ingest/extract_pdf.py` · `ingest/normalize.py` | ссылка · чужой PDF · нормализация. Все трое принимают `--слаг <slug>` — под ним и ведут файлы |
| `transcribe.py` | запись голоса/видео → текст с таймкодами, **локально** |
| `screencast_steps.py` | скринкаст → кадры по смыслу с таймкодами |
| `make_grid.py` · `annotate_shots.py` | сетка координат · номерные рамки «куда жать» на скринах |
| `render.py` | HTML → PDF (Chromium, `print_background=True`) |
| `check_links.py` · `qa_screenshots.py` | сколько ссылок кликабельны · картинки страниц для проверки глазами |
| `prep_photo.py` | фото → круглый кадр для страницы об авторе |
| `illustrate.py` | AI-картинки (**опция**, нужен ключ; без ключа — заглушки) |

## 6 · Границы — говорить честно, не умалчивать

- **Платные сервисы не обязательны.** Без ключей система собирает документ полностью;
  AI-картинки просто заменяются векторными заглушками.
- **Система не ходит по сервисам сама** и не логинится под пользователем. Кадры для инструкций
  приносит человек — записью экрана или своими скриншотами.
- **Рамки со скринкаста приблизительные** (кадр берётся как есть, с курсором). Точные рамки —
  только со своих скриншотов, по измеренным координатам.
- **Свой фирменный шрифт** — нужен файл `.ttf`, и встанет не любой. Готовый набор — в `setup.sh`.
- **Расшифровка идёт локально**, записи никуда не уезжают. Первый запуск качает модель (~1,5 ГБ).

## 7 · Тон в разговоре с человеком

Это система для людей, которые не программисты. Говори просто, по-человечески, без жаргона.
Ошибку объясняй так, чтобы было понятно, что делать дальше. Не обещай того, чего система не
умеет, — честная граница лучше приятного обещания. Сломалось — `ЕСЛИ-СЛОМАЛОСЬ.md`.
