# Сборщик документов

Приносите то, что у вас уже есть, — забираете готовый документ: свёрстанный PDF с обложкой,
кликабельным содержанием, схемами и страницей об авторе. В ваших цветах и с вашим именем.

**Что можно принести:** текст или статью · ссылку на страницу · чужой PDF · запись разговора
или голосовое · запись экрана, на которой вы вслух рассказываете, что делаете.

**Что получается:** методичка · инструкция для клиента или сотрудника · руководство к своему
продукту · гид для новичка · коммерческое предложение.

---

## Как поставить

Скажите своей нейросети (Claude Code, Codex, Kimi Code — любой из них):

> Забери систему по ссылке `<адрес этого репозитория>`, положи её ко мне в рабочую папку
> и поставь. Сначала расскажи, что собираешься сделать, — потом делай.

Она скачает систему, поставит окружение и доложит, куда положила. Разово ставится браузер
для печати PDF — это несколько сотен мегабайт и несколько минут. Медленно — нормально.

Вручную то же самое:

```bash
bash scripts/setup.sh                      # один раз
.venv/bin/python scripts/selftest.py       # проверить, что всё работает
```

## Первый запуск

Система спросит, **чей это документ**: имя, чем занимаетесь, цвета, контакты. Ответы лягут в
профиль — и дальше каждый документ будет выходить в вашем оформлении.

```
/setup     — завести профиль (или ещё один)
/pdf       — собрать документ из источника
```

Профилей может быть сколько нужно: **себе**, **клиенту**, **основной работе**. Один и тот же
текст, собранный в разных профилях, выйдет разными документами — переверстать под другой
бренд можно одной фразой.

## Что система умеет — и чего не умеет

**Умеет:** собрать документ из текста, ссылки, чужого PDF, записи голоса или экрана ·
расшифровать запись **локально**, ничего не отправляя наружу · сверстать пошаговую инструкцию
со скриншотами и номерами «куда жать» · собрать один и тот же документ в разных профилях ·
проверить себя после сборки: кликабельны ли ссылки, не вылезло ли что-то за страницу.

**Не умеет — и это честно:**

- не ходит по сайтам и сервисам сама и не логинится под вами. Кадры для инструкции приносите
  вы — записью экрана или скриншотами;
- рамки «куда жать», взятые из записи экрана, стоят **приблизительно** (кадр берётся как есть,
  вместе с курсором). Точно на кнопках — только по вашим скриншотам;
- ваш фирменный шрифт возьмёт, если есть файл `.ttf`, и встанет не любой. Готовый набор
  ставится сразу;
- красивые AI-картинки — опция и требуют ключа. Без ключа документ собирается полностью,
  с векторными заглушками.

## Если решите выложить свою систему

Систему можно положить на полку — себе про запас, на второй компьютер, коллеге. **Данные при
этом остаются дома.** Перед выкладкой посмотрите глазами, что именно уезжает:

```bash
.venv/bin/python scripts/что_уедет.py <папка системы>
```

Он покажет список и отдельно — то, что похоже на личное: выписки, чеки, отчёты с вашими
цифрами, ключи доступа, записи. Добавить находки в исключения — тем же скриптом с `--закрыть`.

⛔ Выложенное в открытый доступ остаётся в истории, даже если файл потом удалить. Поэтому
смотрим **до**, а не после.

## Что-то пошло не так

Откройте [ЕСЛИ-СЛОМАЛОСЬ.md](ЕСЛИ-СЛОМАЛОСЬ.md) — там по симптомам, простым языком.
Быстрый ответ почти всегда один: `.venv/bin/python scripts/selftest.py` и показать системе,
что она написала.

## Что где лежит

| Папка | Что внутри |
|---|---|
| `профили/` | ваши профили: имя, цвета, логотип, контакты. **Наружу не уезжают** |
| `input/` | то, что вы принесли: записи, скриншоты, файлы |
| `ingest/` | вычищенный текст источника — из него верстается документ |
| `output/` | готовые PDF |
| `templates/`, `scripts/`, `.claude/` | сама система: шаблоны, скрипты, правила |

Карта системы для нейросети — в `CLAUDE.md` (и `AGENTS.md` для Codex и Kimi).
